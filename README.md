# Nonye Niyi-Afolabi Portfolio

Single-page portfolio site. The whole site is the one file `index.html`.

## Put it online with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository.
3. Go to Settings > Pages.
4. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
5. Wait 1 to 2 minutes. The site goes live at `https://USERNAME.github.io/REPO-NAME/`.
